## 개요

여러 파일에서 중복으로 정의되어 있던 타입과 유틸리티 함수들을 `src/types/common.types.ts` 파일로 통합하여 코드 중복을 제거하고 유지보수성을 향상시켰습니다.

**작업 일시**: 2025-01-05  
**작업 범위**: 타입 정의, 상수, 유틸리티 함수 통합

## 트러블슈팅

### 🔴 문제 1: 타입 호환성 문제

**증상**:

```
Type 'string' is not assignable to type 'DayOfWeek'
```

**원인**:

- `convertDayNameToDayOfWeek` 함수의 반환 타입이 `string`이었음
- `DayOfWeek` 타입으로 명시적으로 캐스팅이 필요했음

**해결**:

```typescript
// Before
const convertDayNameToDayOfWeek = (dayName: string): string => {
  return dayMap[dayName] || "MONDAY";
};

// After
export const convertDayNameToDayOfWeek = (dayName: string): DayOfWeek => {
  const normalized = dayName.replace("요일", "").trim();
  return DAY_NAME_TO_DAY_OF_WEEK[normalized] || "MONDAY";
};
```

### 🔴 문제 2: 기존 코드와의 호환성

**증상**:

- `post.type.ts`에서 `DAY_OF_WEEK_MAP`을 export하고 있었는데, 다른 파일에서 이를 import하고 있음
- 통합 후 export가 사라지면 기존 코드가 깨짐

**해결**:

```typescript
// post.type.ts
// 공통 상수는 common.types.ts에서 import
import { SERVER_MAPPING, DAY_OF_WEEK_MAP } from "./common.types";
export { SERVER_MAPPING, DAY_OF_WEEK_MAP }; // 재export하여 호환성 유지
```

### 🔴 문제 3: 함수 시그니처 차이

**증상**:

- `MatchFormPage.tsx`의 `formatDate`는 `Date | null`을 받음
- `MatchResultCard.tsx`의 `formatDate`는 `string | undefined`를 받음
- 두 함수의 시그니처가 달라 통합이 어려움

**해결**:

- 용도별로 함수를 분리하여 명확한 네이밍 적용

```typescript
// Date 객체 → ISO 문자열
export const formatDateToISO = (date: Date | null): string => { ... };

// 날짜 문자열 → 한글 형식
export const formatDateToKorean = (dateStr?: string): string => { ... };

// 날짜 문자열 → YYYY.MM.DD 형식
export const formatDateToDot = (dateStr: string): string => { ... };
```

### 🔴 문제 4: 요일 매핑 상수 이름 충돌

**증상**:

- `DAY_OF_WEEK_MAP`: 영문 → 한글 (예: "MONDAY" → "월")
- `DAY_KR_MAP`: 영문 → 한글 요일명 (예: "MONDAY" → "월요일")
- 두 상수의 용도가 비슷하지만 이름이 달라 혼란 발생

**해결**:

- 명확한 네이밍으로 통일

```typescript
// 영문 → 한글 (요일 제외)
export const DAY_OF_WEEK_MAP: Record<DayOfWeek, string> = {
  MONDAY: "월",
  ...
};

// 영문 → 한글 요일명 (요일 포함)
export const DAY_OF_WEEK_FULL_MAP: Record<DayOfWeek, string> = {
  MONDAY: "월요일",
  ...
};
```

### 🔴 문제 5: Date.getDay() 매핑 로직 중복

**증상**:

- `MatchFormPage.tsx`에서 `Date.getDay()` 반환값을 `DayOfWeek`로 변환하는 로직이 중복됨
- 여러 곳에서 동일한 매핑 객체를 정의하고 있음

**해결**:

- 공통 상수와 함수로 통합

```typescript
// 상수 정의
export const DATE_DAY_TO_DAY_OF_WEEK: Record<number, DayOfWeek> = {
  0: "SUNDAY",
  1: "MONDAY",
  2: "TUESDAY",
  3: "WEDNESDAY",
  4: "THURSDAY",
  5: "FRIDAY",
  6: "SATURDAY",
};

// 함수 정의
export const getDayOfWeekFromDate = (date: Date): DayOfWeek => {
  const dayIndex = date.getDay();
  return DATE_DAY_TO_DAY_OF_WEEK[dayIndex] || "MONDAY";
};
```

## 개선 효과

### ✅ 코드 중복 제거

- **타입 중복**: 3개 → 1개 (66% 감소)
- **상수 중복**: 5개 이상 → 1개 (80% 이상 감소)
- **함수 중복**: 10개 이상 → 1개 (90% 이상 감소)

### ✅ 유지보수성 향상

- 공통 타입/함수 수정 시 한 곳만 수정하면 전체에 반영
- 버그 수정 시 일관성 보장
- 새로운 요일 관련 기능 추가 시 중복 없이 확장 가능
