# 뱃지 로직 정리

## 개요

뱃지 시스템은 사용자의 장애 유형별 도움 제공 횟수를 추적하고, 달성한 뱃지를 표시하는 기능입니다. 뱃지 정보는 `/member/members/profile/me` API를 통해 `getMyMemberProfile`로 가져오며, Zustand 스토어를 통해 전역 상태로 관리됩니다.

## 데이터 흐름

```
getMyMemberProfile() 
  → Member.badges (Badge[])
  → useBadgeStore.fetchBadgeStatus()
  → BadgeStatusItem[] 변환
  → useBadgeStore.badgeStatus 저장
```

## 타입 정의

### 1. Badge 타입 (`src/types/member.type.ts`)

서버에서 받아오는 기본 뱃지 정보:

```typescript
export interface Badge {
  disabilityCategoryId: number;  // 장애 유형 ID
  count: number;                  // 달성 횟수
  badgeCode: string | null;      // "LEVEL_1" | "LEVEL_2" | null
}
```

### 2. Member 타입에 badges 필드 추가

```typescript
export interface Member {
  // ... 기타 필드들
  badges: Badge[] | null;  // 뱃지 배열
}
```

### 3. BadgeStatusItem 타입 (`src/domain/Badge/types/badge.type.ts`)

UI에서 사용하는 뱃지 상태 정보:

```typescript
export type BadgeLevel = "LEVEL_1" | "LEVEL_2" | null;

export interface BadgeStatusItem {
  disabilityCategoryIds: number[];  // 장애 유형 ID 배열 (복수형)
  badge_code: BadgeLevel;          // 뱃지 레벨
  count: number;                    // 달성 횟수
}
```

### 4. BadgeResponse 타입

API 응답 타입:

```typescript
export interface BadgeResponse {
  badge_status: BadgeStatusItem[];
}
```

## API 구조

### badgeApi (`src/domain/Badge/api/badgeApi.ts`)

```typescript
export const badgeApi = {
  // 기존 API 엔드포인트 사용 (서버에 별도 엔드포인트가 있는 경우)
  getBadge: async (): Promise<BadgeResponse> => {
    const response = await instance.get<BadgeResponse>("/badge");
    return response.data;
  },

  // getMyMemberProfile에서 badge 정보 가져오기
  getBadgeFromMember: async (): Promise<BadgeResponse> => {
    const response = await getMyMemberProfile();
    const badges = response.data.badges || [];

    // Badge[]를 BadgeStatusItem[]로 변환
    const badgeStatus = badges.map((badge) => ({
      disabilityCategoryIds: [badge.disabilityCategoryId],
      badge_code: badge.badgeCode as "LEVEL_1" | "LEVEL_2" | null,
      count: badge.count,
    }));

    return {
      badge_status: badgeStatus,
    };
  },
};
```

## Store 구조

### useBadgeStore (`src/domain/Badge/store/useBadgeStore.ts`)

Zustand를 사용한 뱃지 상태 관리:

```typescript
interface BadgeState {
  badgeStatus: BadgeStatusItem[];  // 뱃지 상태 배열
  isLoading: boolean;               // 로딩 상태
  error: string | null;             // 에러 메시지

  // 액션
  fetchBadgeStatus: () => Promise<void>;  // 뱃지 정보 가져오기
  setBadgeStatus: (badgeStatus: BadgeStatusItem[]) => void;
  clearBadgeStatus: () => void;
  setLoading: (loading: boolean) => void;
  setError: (error: string | null) => void;

  // 헬퍼 함수
  getBadgeStatusByDisabilityId: (disabilityId: number) => BadgeStatusItem | undefined;
}
```

### 데이터 변환 로직

`fetchBadgeStatus` 함수에서 `Badge[]`를 `BadgeStatusItem[]`로 변환:

```typescript
fetchBadgeStatus: async () => {
  const response = await getMyMemberProfile();
  const badges = response.data.badges || [];

  // Badge 타입: { disabilityCategoryId, count, badgeCode }
  // BadgeStatusItem 타입: { disabilityCategoryIds, badge_code, count }
  const badgeStatus: BadgeStatusItem[] = badges.map((badge) => ({
    disabilityCategoryIds: [badge.disabilityCategoryId],  // 단수 → 복수 배열
    badge_code: badge.badgeCode as BadgeLevel,            // badgeCode → badge_code
    count: badge.count,
  }));

  set({ badgeStatus, isLoading: false });
}
```

## 사용 예시

### 1. Store를 사용한 뱃지 정보 가져오기

```typescript
import { useBadgeStore } from "../store/useBadgeStore";

const MyComponent = () => {
  const { 
    badgeStatus, 
    isLoading, 
    error, 
    fetchBadgeStatus,
    getBadgeStatusByDisabilityId 
  } = useBadgeStore();

  useEffect(() => {
    fetchBadgeStatus(); // getMyMemberProfile에서 badge 정보 가져오기
  }, [fetchBadgeStatus]);

  // 특정 장애 유형의 뱃지 상태 조회
  const status = getBadgeStatusByDisabilityId(1); // 장애 유형 ID: 1

  if (isLoading) return <div>로딩 중...</div>;
  if (error) return <div>{error}</div>;

  return (
    <div>
      {badgeStatus.map((item) => (
        <div key={item.disabilityCategoryIds[0]}>
          장애 유형: {item.disabilityCategoryIds[0]}
          달성 횟수: {item.count}
          뱃지 레벨: {item.badge_code || "미달성"}
        </div>
      ))}
    </div>
  );
};
```

### 3. 기존 코드와의 호환성

기존 코드에서 `badgeApi.getBadge()`를 사용하는 경우:

## 뱃지 레벨 시스템

- **LEVEL_1**: 5회 달성
- **LEVEL_2**: 10회 달성
- **null**: 미달성

## 주요 변경 사항

1. **Member 타입에 badges 필드 추가**: `/member/members/profile/me` 응답에 `badges` 필드 포함
2. **BadgeStatusItem 타입 추가**: UI에서 사용하는 뱃지 상태 정보 타입 정의
3. **useBadgeStore 생성**: 뱃지 정보를 전역 상태로 관리하는 Zustand 스토어
4. **badgeApi 생성**: 뱃지 정보를 가져오는 API 함수 (기존 엔드포인트 및 getMyMemberProfile 지원)

## 주의사항

1. **데이터 변환**: 서버에서 받은 `Badge[]` 타입을 `BadgeStatusItem[]`로 변환해야 UI에서 사용 가능
2. **타입 안정성**: `badgeCode`는 `string | null`이지만, `BadgeLevel`로 타입 캐스팅 필요
3. **에러 처리**: `fetchBadgeStatus`에서 에러 발생 시 `error` 상태에 메시지 저장
4. **로딩 상태**: `isLoading` 상태를 활용하여 로딩 UI 표시 가능
